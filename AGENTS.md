# Rules for AI agents working in this repository

As of 2026-09-27, **one agent (Claude Code) works on this repo, directly on `main`**. The frontend agent (Antigravity) no longer has access, and its redesign has been merged. Read [BUILD-DIRECTIVE.md](BUILD-DIRECTIVE.md), [TRAPS.md](TRAPS.md) and [docs/PRD.md](docs/PRD.md) first.

## Rules

- **Only `main` exists and only `main` deploys.** Vercel builds production from `main` and skips every other branch. Never deploy from a terminal or a branch.
- **Commit attribution is the human operator only** (BUILD-DIRECTIVE N7). No `Co-Authored-By` trailers, no "generated by" lines, and no tool attribution in commits.
- **Commit message format:** `<area>: <what changed>` followed by a blank line and why.
- **Never commit secrets.** `.env*` files are gitignored, except `.env.example`.
- **The UI shows only real data or clearly labelled demo or "coming soon" states.** No hardcoded people, prices, audit entries or fake success messages. See [docs/contracts/ui.md](docs/contracts/ui.md).
- **Keep the layers separate.** The frontend never imports the database, and all logic lives in `backend/src/core` ([docs/contracts/core.md](docs/contracts/core.md)).

## Setup

```sh
npm install
cp backend/.env.example backend/.env                # Neon DATABASE_URL + DIRECT_URL
cp frontend/.env.example frontend/.env.local        # same DB URLs, plus AI and Paystack test keys
npm run dev            # http://localhost:3000
```

The local and live sites share one Neon database. Running `npm run db:seed` wipes the live demo data, so only do it on purpose.

## Before you push to main

```sh
npm run typecheck && npm run lint && npm test && npm run build
```
