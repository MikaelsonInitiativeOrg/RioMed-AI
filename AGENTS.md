# Rules for AI agents working in this repository

Two agents work on this repo: a **frontend agent** (UI design) and a **backend agent** (logic and data). Read [BUILD-DIRECTIVE.md](BUILD-DIRECTIVE.md), [TRAPS.md](TRAPS.md) and [docs/PRD.md](docs/PRD.md) first.

## Who owns what

| Area | Owner | Notes |
| --- | --- | --- |
| `frontend/src/app/**` pages, `layout.tsx`, `loading.tsx`, `frontend/src/components/**`, `frontend/src/app/globals.css`, `frontend/public/**`, `frontend/src/lib/format.ts` | Frontend agent | Follow [docs/contracts/ui.md](docs/contracts/ui.md) |
| `backend/**`, `frontend/src/app/actions.ts`, `frontend/src/app/api/**`, `frontend/src/app/pay/callback/**`, `frontend/src/lib/session.ts` | Backend agent | Follow [docs/contracts/core.md](docs/contracts/core.md) |
| Root files, `docs/**`, `implementation.md`, `package.json` files | Both, by agreement | Say what you changed in the PR |

Never edit files the other agent owns. To ask for a change, add it to the "Requests" section of `docs/contracts/ui.md`.

## Git

- Work on a branch: `design/<topic>` for the frontend, `core/<topic>` for the backend. Open a PR into `main`. Each agent reviews the other's PRs.
- Pull and rebase on `main` before you push. Keep PRs small and merge them often. Today's deadline is 17:30 WAT.
- **Commit attribution is the human operator only** (BUILD-DIRECTIVE N7). No `Co-Authored-By` trailers, no "generated by" lines, and no tool attribution in commits or PRs.
- Commit message format: `<area>: <what changed>` followed by a blank line and why.
- Never commit secrets. `.env*` files are gitignored, except `.env.example`.

## Setup

```sh
npm install
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env.local
npm run db:push && npm run db:seed
npm run dev            # http://localhost:3000
```

## Before you push

```sh
npm run typecheck && npm run lint && npm test && npm run build
```

- **Frontend agent:** also open every page you touched at a 360 px width. Check that its empty, error and loading states still render.
